# Hack The Box — Odori

A hands-on penetration testing lab focused on network enumeration, Windows disk forensics, credential analysis, and Linux privilege escalation.

**Tools:** Nmap, SMBClient, John the Ripper, Dislocker, Mimikatz, SSH/SFTP, pspy, Python.

**Key skills:** Network reconnaissance, SMB enumeration, BitLocker analysis, Windows registry examination, credential recovery, Linux service analysis, and privilege escalation.

**Environment:** Kali Linux, Windows disk image, Linux server.

*For educational purposes and authorized lab environments only.*
